# Spooky Ghost House Simulator

A multiplayer ghost hunting game built with Unity 6 (URP).

## Features (Planned)

- First-person exploration
- Ghost AI
- Procedurally selected ghost types
- Evidence collection
- Equipment progression
- Multiplayer investigation
- Dynamic hauntings

## Technologies

- Unity 6
- Universal Render Pipeline (URP)
- C#
- Git
- GitHub
